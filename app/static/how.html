01

A question comes in, in any of six languages

English, Finnish, German, French, Italian or Dutch. The question is about one drawing: a CAD plan, a BIM model or a scanned plan. These are real test questions. Pick a language to see one.

A router picks the method from the file kind, and reads the question type from keywords in ten languages. Each question goes to the cheapest method that can answer it exactly.

Who answers the 25,420 test questions. Exact CAD or IFC geometry takes 34.7 %. Our own trained detector, with a fine-tuned vision model as second opinion, takes 64.9 %. Claude Haiku 5.5 is called only for the 110 free-text questions: 0.4 %.

The model only chooses what to measure. Geometry does the measuring. 99.6 % of questions make no paid model call. When a method is unsure, it says “not sure” instead of guessing.

02

The answer is counted out on the drawing

Asked in German about a Swiss apartment plan: “Wie gross ist die Nettowohnfläche von Wohnung A in m²?” (the net living area of apartment A). The plan comes with its CAD file, so the answer can be read exactly.

Every room that counts is outlined from the CAD layers and gets a row with its own m². The list is the answer: the rows add up to the total.

62.74 m², the dataset’s answer. A second method re-reads the PDF alone and agrees. Claude Sonnet 5.5, given the drawing and its CAD file, said 73.8 m². No model call here: $0.

Disagree? Untick a room. The total recomputes on the spot and the correction is kept as feedback. Try it in the list.

03

Four ways to check it

1 · Evidence that adds up. Boxes, room outlines and BIM elements sum to the answer, so a reviewer checks arithmetic, not a picture. We measured the boxes themselves, not only the totals.

2 · Confidence you can take literally. If the router answers only at confidence ≥ 0.5 and says “not sure” otherwise, it answers 87.6 % of all questions at 95.8 % accuracy, turning 1,594 wrong answers into honest abstentions. Hover or use the arrow keys on the curve.

3 · A second opinion. A different method re-derives every answer. On scanned plans it is our fine-tuned Qwen3-VL-8B. When it agrees, the detector is right 94.9 %. On a conflict the confidence is halved and both sets of marks are shown, never silently swapped.

4 · Every LLM number traced. In free-text answers, each number and name must appear in the fact lines the model cited, or the answer is flagged. 97 % of 4,328 claims on test trace.

04

About 1,900× cheaper, and more often right

90.0 % vs 69.8 %. The fair comparison is Claude Sonnet 5.5 given the drawing and its CAD / IFC files, the same inputs our methods read: +20 points for us. Lines show 95 % intervals; the frontier models answered a 400-question sample re-weighted to the test mix.

$0.013 vs $25.76 per 1,000 questions in API fees. Numeric answers make no paid call at all; only the 110 free-text questions call Claude Haiku. The scale is logarithmic: each gridline is ten times the last.

One dot is our API bill for 1,000 questions. Sonnet with the files costs about 1,900 of them for the same 1,000. Our local compute adds ~$0.006, and we answer in 0.04 s instead of 15.7 s.
